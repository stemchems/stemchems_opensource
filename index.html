02Ion Classification & Naming

Monatomic anions

  • Add suffix -ide: Oxygen → oxide (O²⁻), Chlorine → chloride (Cl⁻)

Ion types

  • Monatomic = 1 atom  ·  Polyatomic = 2 or more atoms bonded together
  • Cation (+) e.g. Li⁺, Ca²⁺, Mg²⁺  ·  Anion (–)

Naming multivalent metals

  • Stock system → English element name + Roman numeral, e.g. Iron(II)
  • Classical system → old Latin-root name: -ous (lower charge) / -ic (higher charge)

03Isotope Notation Practice

Method for a neutral atom

  • p⁺ = atomic number (Z, bottom-left of the notation)
  • e⁻ = p⁺ (neutral) — adjust by the ion's charge if it's an ion
  • n⁰ = mass number (A, top-left) − atomic number (Z)
  • Valence e⁻ = main-group number's last digit (e.g. Group 17 → 7 v.e.)
